# Решения и план

## Что решено

- **Формат**: книга-сайт из 26 коротких глав (5 частей), отдельная HTML-страница на главу,
  общие `style.css` / `toc.js` / `app.js`. Работает офлайн, печатается, темы light/dark.
- **Единица главы**: «зачем → якорь → ряд из 8 звеньев → схема → лаборатория → мост → ошибки →
  вопросы → задачи → чек-лист».
- **Сквозная система метафор** — главная ставка. Одна модель объясняет Python, pandas и SQL:
  - хеш-таблица: гардероб с номерками → `dict`, индекс pandas, `hash join`, B-tree;
  - «разложить — посчитать — собрать»: `get`/`defaultdict` → `groupby` → `GROUP BY`;
  - «оглавление книги»: индекс pandas / индекс SQL / метка `loc`;
  - «трафарет»: boolean-маска NumPy → булева фильтрация pandas → `WHERE`.
- **Картинки**: векторные схемы в SVG, генерируются кодом, правятся текстом. Нейрокартинки для
  технических глав не используем — они не дают точности.
- **Проверяемость**: весь код глав запускается локально (Python 3.12 / numpy 2.3.5 / pandas 3.0.1),
  SQL — на локальном PostgreSQL 14 с учебной БД `learning_shop` (ещё не создана).
- **Прогресс**: чек-листы в localStorage, счётчик «освоено глав» в сайдбаре.

2. Часть I целиком (01–06) + входная диагностика Python-коллекций (10 задач, 20 минут).
3. Часть II (NumPy, 5 глав) — схемы broadcasting, axis, view/copy.
4. Часть III (pandas, 7 глав) — реальный CSV-датасет в `snippets/`.
5. БД `learning_shop` + часть IV (SQL, 6 глав) — все запросы проверены через psql.
6. Часть V: интеграция и проект; PDF-экспорт (Chromium + print CSS).

## Решение от 25 ноября: офлайн-книга сейчас, сервис — потом

Пользователь выбрал: полноценный сервис откладываем (мало материала и авторов), сейчас важно
читать офлайн с телефона и иметь страницу на GitHub Pages. Сделано:

- PWA: `manifest.webmanifest`, `sw.js` (39 файлов, версия = хеш содержимого), иконки 180/192/512.
- Читалка на телефоне: размер текста А−/А+, «продолжить чтение» на обложке, позиция в главе.
- Мобильная шапка: бренд + кнопка «Оглавление», меню-шторка с читалкой.
- Публикация: `.github/workflows/pages.yml` (артефакт — `guide/`), инструкция в README.
- `start.command` для локального сервера и проверки PWA.
- Проверки: `tools/pwa-check.cjs`, `tools/reader-check.cjs`, `tools/check-links.cjs`.
- Репозиторий инициализирован, первый коммит в ветке `main`.

Ограничение: офлайн-кэш включается только на https (GitHub Pages) или localhost; при `file://`
service worker недоступен. Поэтому страница на Pages — не «плюс», а условие офлайна на телефоне.
