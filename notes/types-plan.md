# Справочник по типам данных: план

Книга закрыта: 26 глав, 4 проверочные, приложение с лабораториями. Глава 01 «Карта коллекций»
отвечает на вопрос «что взять», но не «как этим пользоваться»: методы там упомянуты вскользь,
полных таблиц нет. Запрос: отдельный гайд по каждому типу из главы 01 — описание, методы,
примеры, как работать — в том же стиле, что и главы.

## Решение в одном абзаце

Добавляем в книгу раздел **«Справочник»** — 8 страниц: хаб и 7 типов из главы 01
(`list`, `tuple`, `dict`, `set`, `Counter`, `defaultdict`, `deque`). Раздел не входит
в 8-недельную программу и не меняет счётчик «освоено глав»: это reference, к которому
возвращаются за методом, а не главы для чтения подряд. Каждая страница — мини-глава
на 12–15 минут в том же шаблоне, с теми же метафорами и сквозными данными.

Почему не одна длинная страница: 7 типов × таблицы методов — это бесконечная прокрутка
на телефоне. В книге уже принято «одна страница — одна тема».

## Методы: что обязательно покрыть

| Тип | Полный список методов | Синтаксис/операторы | Цена | Методы из гл. 01 |
|---|---|---|---|---|
| `list` | append, extend, insert, remove, pop, clear, index, count, sort, reverse, copy | `+`, `*`, `in`, `len`, срезы, `del` | в конец O(1)*, в середину O(n), `in` O(n) | срезы, `pop(0)`, `insert(0)`, `append` |
| `tuple` | count, index | `+`, `*`, `in`, `len`, срезы, распаковка | доступ O(1), поиск O(n) | — |
| `dict` | get, setdefault, update, pop, popitem, fromkeys, keys, values, items, copy, clear | `in`, `len`, `d[k] = v`, `del`, `\|` | O(1) в среднем | `get` |
| `set` | add, remove, discard, pop, clear, copy, update, union, intersection, difference, symmetric_difference, `*_update`, issubset, issuperset, isdisjoint | `&`, `\|`, `-`, `^`, `<=`, `in` | O(1) в среднем; `&` O(min) | `&` |
| `Counter` | most_common, elements, total, update, subtract, clear, copy | `c[k] += 1`, `+`, `-`, `&`, `\|` | `most_common(n)` O(n log k) | `most_common` |
| `defaultdict` | default_factory, `__missing__` + все методы `dict` | `d[k]` на чтение создаёт ключ | как `dict` | `defaultdict(list)` |
| `deque` | append, appendleft, pop, popleft, extend, extendleft, rotate, maxlen, clear, copy, count, index, insert, remove, reverse | `in`, `len`, индексация, итерация | O(1) с краёв, в середине O(n) | appendleft, popleft |

\* амортизированно. Наличие и точное поведение каждого метода сверять по docs 3.12 при
написании (например, `Counter.total()` — с 3.10; `deque.index/count` — есть, `deque`
не поддерживает срезы и не hashable).

## Содержание по типам (тезисы)

**list.** Упорядоченная изменяемая последовательность: массив указателей, доступ по индексу
O(1), вставка/удаление в середине O(n). Сценарии: стек (`append`/`pop`), накопление,
сортировка с `key`, топ-N, `enumerate`. Ошибки: `b = a` (алиас, не копия), `sort()` возвращает
`None`, `remove(x)` по значению против `pop(i)` по индексу, изменение списка в цикле,
`in` по списку внутри цикла. Мостик: `Series`, `ndarray`, срезы.

**tuple.** Неизменяемая запись: компактнее списка, hashable, годится в ключ и в элемент
множества. Сценарии: координата/запись, возврат нескольких значений, распаковка, ключ
словаря. Ошибки: `(1)` — это число, а не tuple; tuple с изменяемым элементом нехешируем;
tuple для данных, которые будут меняться. Мостик: ключ `dict`, `MultiIndex`, `dataclass`
как изменяемая альтернатива.

**dict.** Хеш-таблица: `hash(key)` → ячейка → значение, O(1) в среднем, порядок вставки
сохраняется. Сценарии: JSON/конфиг, кэш, счётчик, группировка, `items()`. Ошибки: `KeyError`
вместо `get`, изменяемый ключ, `fromkeys` с изменяемым значением, изменение словаря
во время итерации, `get` против `defaultdict`. Мостик: индекс pandas и `loc`, B-tree и
`hash join` в SQL.

**set.** Уникальность и операции над множествами: `&`, `|`, `-`, `^`, проверка входа
за O(1). Сценарии: дедупликация, пересечение тегов, права/участники, `frozenset` как ключ.
Ошибки: `{}` — это `dict`, `remove` бросает `KeyError` против `discard`, порядок
не гарантирован, `update("abc")` разбирает строку на буквы. Мостик: `isin`, `IN`, `EXISTS`,
`DISTINCT`, `UNION`.

**Counter.** Словарь частот: чтение отсутствующего ключа даёт 0, `most_common(n)`,
`elements`, `total`, арифметика `+ - & |`. Сценарии: частоты слов/статусов, топ-N,
сравнение наборов. Ошибки: `most_common()` без `n` на больших данных, нехешируемые
элементы, отрицательные счётчики, путаница `update` (сложение) и `subtract`. Мостик:
`value_counts`, `GROUP BY … COUNT(*)`.

**defaultdict.** Словарь с фабрикой: `d[k]` на чтение создаёт значение, а не бросает
`KeyError`. Сценарии: группировка `defaultdict(list)`, счётчик `defaultdict(int)`,
список смежности, инверсия словаря, вложенные словари. Ошибки: чтение создаёт ключ
(проверка `in` после чтения врёт), `default_factory=None`, вложенность через lambda,
lambda не сериализуется. Мостик: `groupby`, `GROUP BY`.

**deque.** Двусторонняя очередь: O(1) на обоих концах, `maxlen` хранит последние N.
Сценарии: очередь/стек, BFS, скользящее окно, `rotate`. Ошибки: `extendleft` переворачивает
порядок, индексация и `insert` в середине O(n), `maxlen` молча выбрасывает старые элементы,
нет срезов, не hashable. Мостик: прямого аналога нет; «окно» — это `rolling` в pandas.

## Данные и стиль

- Сквозные данные — как в книге: пользователи и заказы (`Anna`, `Olga`, `Ivan`,
  `learning_shop`). Тогда примеры справочника совпадают с главами 02–06 и 19–26.
- Метафоры не выдумываем: поезд и опечатанный контейнер (03), шкаф с номерками (02),
  фейс-контроль (04), ящик с инструментами (06).
- Тон: короткие абзацы, таблица вместо простыни, в вопросах — «тезис → механика →
  ограничение».
- Только Python 3.12. Сложности — по CPython TimeComplexity и docs, не по памяти.
- Всё, что выводится на странице, выведено запуском (принцип книги).
