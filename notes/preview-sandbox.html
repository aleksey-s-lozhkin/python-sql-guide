Pandas: средний чек по пользователям

Дан orders.csv. Посчитайте число заказов и средний чек по каждому пользователю. Результат — DataFrame с колонками name, orders, avg_check. Проверка выполнится в вашем браузере.

solution.pyPyodide · Python 3.12
import pandas as pd

df = pd.read_csv("orders.csv")
result = df.groupby("name").agg(
    orders=("order_id", "count"),
    avg_check=("amount", "mean"),
)

Подсказка: если groupby «съел» строки — проверьте, что name не попал в индекс.
ваша схема: work work.orders work.products
query.sqlPostgreSQL 16 · read-write только work
SELECT u.name,
       COUNT(*) AS orders,
       ROUND(AVG(o.quantity * p.price), 2) AS avg_check
FROM work.orders o
JOIN work.users u ON u.id = o.user_id
JOIN work.products p ON p.id = o.product_id
GROUP BY u.name
ORDER BY avg_check DESC;
