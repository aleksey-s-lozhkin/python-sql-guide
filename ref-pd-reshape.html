Reshape, даты и строки pivot, melt, explode, crosstab, .dt и .str — как переложить таблицу

Одна и та же информация бывает длинной и широкой: melt складывает таблицу, pivot растягивает, explode разворачивает список в ячейке. Плюс два аксессора: .dt для дат и .str для текста.

Самое главное
  • Длинная форма — факты (строка = наблюдение), широкая — отчёт. melt складывает, pivot растягивает.
  • pivot требует уникальных пар (index, columns); при повторах — pivot_table с aggfunc.
  • .dt и .str работают только на своём dtype: сначала to_datetime или строковая колонка, иначе AttributeError.

01Что это и как устроено

Reshape — смена формы таблицы без потери информации. В длинной таблице строка — факт («anna, Q1, 100»), в широкой — объект («anna, Q1=100, Q2=200»). Для groupby и графиков удобнее длинная, для отчёта глазами — широкая.

Два аксессора достают структуру из ячейки: .dt — год, месяц, день, формат и период из даты; .str — обрезать, сменить регистр, найти, разбить и извлечь из текста. Оба требуют подходящего dtype.

🪗
Держите эту картинку в голове

Таблица — гармошка. Растянутая (широкая) — много колонок, мало строк, удобно смотреть глазами. Сложенная (длинная) — мало колонок, много строк, удобно фильтровать, группировать и рисовать.

melt складывает гармошку, pivot растягивает, explode разворачивает список в ячейке. Даты и строки — это «разобрать содержимое ячейки на части». Метафору целиком разбирает глава 18.

Шесть строк, которые надо помнить

pivot — в широкое, melt — обратно, pivot_table — с агрегацией, explode — список в строки, crosstab — пары, concat — склейка.

04Все операции

Три таблицы: форма, даты, строки. В «Примечании» — копия или view и где ловушка. O(...) не привожу: цена reshape зависит от числа групп, параметров и dtype.

05Разбор по группам

Все примеры страницы — в файле ref_pd_reshape_lab.py. Вывод снят на pandas 3.0.1: в других версиях отличаются dtype и оформление таблиц.

pivot: длинная → широкая

ref_pd_reshape_lab.pypython
wide = long.pivot(index="user", columns="quarter", values="amount")
print(wide)
print(wide.columns.tolist())
quarter Q1 Q2 user anna 100 200 ivan 300 400 ['Q1', 'Q2']

index — строки, columns — колонки, values — содержимое ячеек. В выводе quarter стало именем колонок, user — индексом; исходная таблица не изменилась.

pivot на дублях и pivot_table

ref_pd_reshape_lab.pypython
dup = pd.DataFrame({
    "user": ["anna", "anna", "ivan"],
    "quarter": ["Q1", "Q1", "Q2"],
    "amount": [100, 150, 300],
})
try:
    dup.pivot(index="user", columns="quarter", values="amount")
except ValueError as e:
    print(type(e).__name__, e)
print(dup.pivot_table(index="user", columns="quarter", values="amount", aggfunc="sum"))
ValueError Index contains duplicate entries, cannot reshape quarter Q1 Q2 user anna 250.0 NaN ivan NaN 300.0

pivot падает с ValueError: Index contains duplicate entries, если на пару (anna, Q1) приходится две суммы. pivot_table сначала агрегирует (aggfunc="sum"), потом раскладывает — отсюда 250 у anna.

melt: широкая → длинная

ref_pd_reshape_lab.pypython
back = wide.reset_index().melt(id_vars="user", var_name="quarter", value_name="amount")
print(back.to_string(index=False))
print(len(wide), len(back))
user quarter amount anna Q1 100 ivan Q1 300 anna Q2 200 ivan Q2 400 2 4

id_vars остаются колонками, остальные value_vars сворачиваются в две: имя переменной и значение. Две строки стали четырьмя, широких колонок нет.

explode: список → строки

ref_pd_reshape_lab.pypython
baskets = pd.DataFrame({
    "order_id": [1, 2, 3],
    "items": [["apple", "pear"], ["bread"], []],
})
print(baskets.explode("items").to_string(index=False))

explode повторяет остальные колонки для каждого элемента, а пустой список даёт строку с NaN. Скаляр он не трогает: "apple" и "bread" остались как были — 2 → 2.

crosstab и concat

ref_pd_reshape_lab.pypython
events = pd.DataFrame({
    "user": ["anna", "anna", "ivan", "olga"],
    "status": ["paid", "paid", "new", "paid"],
})
print(pd.crosstab(events["user"], events["status"]))

07Пять ошибок, на которых спотыкаются

pivot на повторяющихся парах

ValueError: Index contains duplicate entries, cannot reshape: pivot не умеет агрегировать и падает на двух строках с одной парой.

Сначала агрегировать (groupby) или взять pivot_table(..., aggfunc="sum") — он сам решит, что делать с повторами.
.str на нестроковой колонке

AttributeError: Can only use .str accessor with string values: аксессор не приводит числа к тексту сам.

df["col"].astype("string").str... или astype(str); проверьте, что колонка действительно текстовая.
explode по скаляру

explode не разворачивает строку или число: молча оставляет их одной строкой. Ошибки нет — и это хуже: данных не прибавилось.

Список в ячейке — explode; строка с разделителем — .str.split(",", expand=True), затем explode по нужной колонке.
melt путает id_vars и value_vars

Без id_vars в длинную форму уйдут все колонки, включая идентификаторы; перепутанные var_name и value_name дадут колонки не с теми названиями.

Явно: melt(id_vars=["user"], value_vars=["Q1", "Q2"], var_name="quarter", value_name="amount") и проверка списка колонок после.
to_datetime с неоднородным форматом

ValueError: time data "05.02.2024" doesn't match format "%Y-%m-%d": формат выведен по первой строке, а вторая уже другая.

Единый format="%d.%m.%Y", либо format="mixed" (медленнее), либо errors="coerce" и проверка isna() после.

08Мини-проверка

Пять вопросов и две задачи. Сначала своя попытка — потом спойлер.

Чем pivot отличается от pivot_table?

pivot только раскладывает значения и требует уникальных пар. pivot_table сначала агрегирует повторы через aggfunc (по умолчанию mean). Если дубли возможны — сразу pivot_table.

Резюме: pivot — раскладка, pivot_table — агрегат + раскладка.
Что делает melt и как вернуть широкую форму?

melt складывает колонки в две: имя переменной и значение; обратная операция — pivot. Ограничение: порядок смысловых групп не сохраняется, а разные dtype могут стать общим типом.

Резюме: melt — вниз по колонкам, pivot — обратно, если пары уникальны.
Зачем explode и чего он не делает?

explode разворачивает список в ячейке в строки, повторяя остальные значения. Чего не делает: не разбирает строку и не трогает скаляры — для строки сначала .str.split(",", expand=True).

Резюме: explode работает со списком, а не с текстом.
Как извлечь месяц из даты и почему строки не сортируются как даты?

Сначала pd.to_datetime(col), затем .dt.month и .dt.to_period("M") для группы с годом. Строки не подходят: «2024-10-01» лексикографически меньше «2024-2-01», и арифметики дат нет.

Резюме: сначала to_datetime, потом .dt.
Как достать домен из email через .str?

Нормализовать .str.strip().str.lower(), затем .str.extract(r"@([\w.]+)$", expand=False); без expand=False вернётся DataFrame. Строки без «@» дают NaN — сигнал грязных данных.

Резюме: .str.extract делает из текста колонку.

Показать решение и разбор

orders = pd.DataFrame({
    "user": ["anna", "anna", "ivan", "anna"],
    "date": ["2024-01-05", "2024-02-11", "2024-01-20", "2024-03-02"],

02 Домены из email

Нормализуйте email и посчитайте, сколько адресов на каждом домене.

условиеpython
users = pd.DataFrame({
    "email": [" Anna@Mail.RU ", "ivan@corp.io", "olga@mail.ru", "petr@corp.io"],
})
# ожидается: {'corp.io': 2, 'mail.ru': 2}
Показать решение и разбор
решениеpython
users = pd.DataFrame({
    "email": [" Anna@Mail.RU ", "ivan@corp.io", "olga@mail.ru", "petr@corp.io"],
})
users["email"] = users["email"].str.strip().str.lower()
users["domain"] = users["email"].str.extract(r"@([\w.]+)$", expand=False)
print(users["domain"].value_counts().sort_index().to_dict())

Что важно. Сначала strip и lower, иначе « Anna@Mail.RU » и «anna@mail.ru» разные. Потом extract и value_counts; sort_index() фиксирует порядок.

09Мостик: GROUP BY, CASE и строки в SQL

Pivot в SQL делают через CASE

мост в SQLsql
-- «месяцы в колонки»: pivot_table на языке SQL
SELECT user,
       SUM(CASE WHEN month = '2024-01' THEN amount END) AS "2024-01",
       SUM(CASE WHEN month = '2024-02' THEN amount END) AS "2024-02"
FROM orders
GROUP BY user;

В SQL нет pivot: таблица всегда длинная, а широкий отчёт собирают через CASE WHEN и агрегаты. В pandas это pivot_table, в SQL — GROUP BY с условными суммами.

Даты и строки: .dt и .str на языке SQL

мост в SQLsql
-- месяц: как dt.to_period("M")
SELECT DATE_TRUNC('month', created_at) AS month,
       SUM(amount) AS total
FROM orders
GROUP BY 1
ORDER BY 1;

-- части даты: как dt.year и dt.month
SELECT EXTRACT(YEAR FROM created_at), EXTRACT(MONTH FROM created_at)
FROM orders;

-- текст: как .str.strip, .str.lower и .str.extract
SELECT LOWER(TRIM(email)) AS email,
       SUBSTRING(email FROM POSITION('@' IN email) + 1) AS domain
