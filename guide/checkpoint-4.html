B1. Выручка по категориям 2 балла

Посчитайте выручку и число заказов по каждой категории товаров, отсортируйте по выручке.

B1sql
-- orders id, product_id, quantity
-- products id, category, price
Показать решение
решениеsql
SELECT p.category, COUNT(*) AS orders,
       SUM(o.quantity * p.price) AS revenue
FROM orders o
JOIN products p ON p.id = o.product_id
GROUP BY p.category
ORDER BY revenue DESC;

B2. Активные пользователи 2 балла

Выведите пользователей с числом заказов больше одного и их суммарной выручкой.

Показать решение
решениеsql
SELECT u.name, COUNT(*) AS orders,
       SUM(o.quantity * p.price) AS revenue
FROM orders o
JOIN users u ON u.id = o.user_id
JOIN products p ON p.id = o.product_id
GROUP BY u.name
HAVING COUNT(*) > 1
ORDER BY revenue DESC;
Anna | 3 | 76950.00 Olga | 2 | 76500.00 Ivan | 2 | 23800.00

Критерии. HAVING, а не WHERE; правильные соединения.

Оценка:

B3. Самый дорогой заказ на пользователя 2 балла

Оставьте по одному заказу с максимальной выручкой на каждого пользователя.

Показать решение
решениеsql
WITH ranked AS (
    SELECT u.name, o.id, (o.quantity * p.price) AS revenue,
           ROW_NUMBER() OVER (PARTITION BY o.user_id
                              ORDER BY o.quantity * p.price DESC) AS rn
    FROM orders o
    JOIN users u ON u.id = o.user_id
    JOIN products p ON p.id = o.product_id
)
SELECT name, id, revenue FROM ranked WHERE rn = 1;

Критерии. Окно в CTE, фильтр по rn снаружи.

Оценка:

B4. Гостевые заказы 2 балла

Найдите заказы без пользователя и их долю в общей выручке.

Показать решение
решениеsql
SELECT COUNT(*) AS guest_orders,
       SUM(o.quantity * p.price) AS guest_revenue
FROM orders o
JOIN products p ON p.id = o.product_id
WHERE NOT EXISTS (SELECT 1 FROM users u WHERE u.id = o.user_id);
guest_orders | guest_revenue --------------+--------------- 1 | 900.00

Критерии. NOT EXISTS (или LEFT JOIN + IS NULL), а не NOT IN без оговорок.

C1. SQL → pandas 2 балла

Перепишите запрос из B2 (активные пользователи) в pandas. Какие методы соответствуют WHERE, JOIN, GROUP BY и HAVING?

Показать решение
pandaspython
orders["revenue"] = orders["quantity"] * products["price"]
merged = orders.merge(users, on="user_id")       # JOIN
merged["revenue"] = merged["quantity"] * products["price"]
summary = merged.groupby("name").agg(
    orders=("id", "count"),
    revenue=("revenue", "sum"),
)
result = summary[summary["orders"] > 1]           # HAVING

Критерии. merge вместо JOIN, groupby+agg вместо GROUP BY, маска вместо HAVING.
