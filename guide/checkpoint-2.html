B2. Суммы по осям 2 балла

Для матрицы 3×4 посчитайте суммы по столбцам и по строкам. Определите, в какой строке сумма максимальна.

B2python
m = np.arange(12).reshape(3, 4)
Показать решение
решениеpython
print(m.sum(axis=0))          # (4,)
print(m.sum(axis=1))          # (3,)

[12 15 18 21] [ 6 22 38] 2

Критерии. axis=0 сворачивает строки, axis=1 — столбцы; argmax возвращает номер строки, а не сумму.

B3. Центрирование по столбцам 2 балла

Вычтите из каждого столбца его среднее так, чтобы форма результата осталась (3, 4), и проверьте, что средние стали нулевыми.

Показать решение
решениеpython
means = m.mean(axis=0, keepdims=True)   # (1, 4)
centered = m - means
print(centered.shape)
print(centered.mean(axis=0))
(3, 4) [0. 0. 0. 0.]

Критерии. keepdims=True и объяснение: (1,4) однозначно говорит «среднее по столбцу», а (4,) выровнялось бы по последней оси.

B4. Найдите баг с копией 2 балла

Функция должна возвращать «очищенный» массив, не меняя входной. Почему после вызова меняется arr? Исправьте.

B4python
def clean(data):
    data[data < 0] = 0
    return data

arr = np.array([-1, 2, -3])
clean(arr)
Показать решение
решениеpython
def clean(data):
    out = data.copy()
    out[out < 0] = 0
    return out

arr = np.array([-1, 2, -3])
print(clean(arr), arr)   # [0 2 0] [-1  2 -3]
[0 2 0] [-1 2 -3]

Критерии. Объяснено, что присваивание по маске меняет массив на месте; копия — явный контракт «не трогаю чужие данные».

Дан DataFrame с колонками age и salary. Запишите: сумму по столбцам, фильтр по возрасту, среднюю зарплату отфильтрованных.

Показать решение
решениеpython

C2. Copy-on-Write 2 балла

Почему в pandas 3 df["salary"][0] = 0 не меняет таблицу? Как записать правильно и как это связано с view/copy в NumPy?

Показать решение
решениеpython
df.loc[0, "salary"] = 0

df["salary"] возвращает промежуточный Series, а не таблицу; CoW гарантирует, что производные объекты не меняют исходную таблицу. Это родственник правила «маска — копия»: менять данные нужно явной операцией записи, а не через промежуточное представление.

Критерии. Указано, что цепочка создаёт промежуточный Series; правильная запись — .loc; проведена параллель с view/copy.
