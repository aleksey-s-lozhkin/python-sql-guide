Самое главное
  • ndarray — сетка чисел одного dtype; размеры идут по осям, а не «по элементам».
  • Две главные развилки: ось (axis=0 против 1) и view или copy — срез смотрит в память, маска копирует.
  • Операции векторизованы: цикл по элементам почти всегда медленнее и длиннее.

01Как пользоваться

  1. Найдите задачу в карте. Создать, выбрать элементы, свернуть по оси, совместить формы, понять копию/view.
  2. Откройте страницу. Вверху — зачем, в середине — таблицы операций с формой результата, внизу — ошибки и сценарии.
  3. Проверьте формой. Каждая страница ссылается на лабораторию ref_np_*_lab.py: запустите и напечатайте .shape — форма объясняет больше, чем текст.
Версия и требования

Лаборатории сняты на numpy 2.3.5 (Python 3.12). В numpy 2 изменились некоторые детали copy= и удалены старые псевдонимы dtype — если вывод не совпал, сначала сверьте версию.

Оси нумеруются с нуля: для таблицы axis=0 — вниз по строкам, axis=1 — вправо по столбцам. Подробно — страница 03.

04Конвертации: list, dtype, reshape

конвертацииpython
import numpy as np

arr = np.array([[1, 2, 3], [4, 5, 6]])
print(arr.shape, arr.ndim, arr.size, arr.dtype)
print(arr.T.tolist())            # транспонирование → список
print(arr.reshape(3, 2).tolist())  # другая форма, те же данные
print(arr.ravel().tolist())      # плоский массив
print(arr.mean(axis=0).tolist()) # среднее по столбцам
print(arr.astype("float64").dtype)  # приведение типа — копия
(2, 3) 2 6 int64 [[1, 4], [2, 5], [3, 6]] [[1, 2], [3, 4], [5, 6]] [1, 2, 3, 4, 5, 6] [2.5, 3.5, 4.5] float64

Вывод получен на numpy 2.3.5. tolist() — обратно в Python-список; astype всегда создаёт копию, reshape — view, если данные позволяют.
