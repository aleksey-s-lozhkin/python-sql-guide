Приложение Справочник готово

Файлы лабораторий Все скрипты книги в одном месте — с командой запуска

В главах код показан фрагментами. Здесь — полные файлы: открыть с номерами строк, скачать и запустить у себя. Каждый файл соответствует главе или странице справочника и воспроизводит её вывод.

🐍 Python 3.12 🐘 PostgreSQL 14 📄 56 файлов 📦 numpy · pandas

01Как открыть и запустить

Каждое имя файла — ссылка: она открывает просмотрщик с нумерацией строк, кнопками «Скачать» и «Копировать». Запуск — из корня проекта:

терминалshell
# Python-лаборатория
python3 guide/snippets/02_dict_lab.py

# SQL-лаборатория (нужна база learning_shop)
bash tools/setup_db.sh
psql -d learning_shop -f guide/snippets/20_select_where.sql

Если книга открыта файлом, просмотрщик не сможет прочитать соседний файл — браузер блокирует такие запросы. Запустите локальный сервер (start.command) или скачайте файл из просмотрщика.

11Учебная база и порядок запуска

терминалshell
# 1. создать базу и загрузить схему с данными
bash tools/setup_db.sh

# 2. подготовка для SQL-справочника: orders_big и статистика
psql -d learning_shop -f guide/snippets/ref_sql_setup.sql

# 3. SQL-главы 19–23
psql -d learning_shop -f guide/snippets/19_order_of_execution.sql
psql -d learning_shop -f guide/snippets/20_select_where.sql
psql -d learning_shop -f guide/snippets/21_group_by_having.sql
psql -d learning_shop -f guide/snippets/22_subqueries_cte.sql
psql -d learning_shop -f guide/snippets/23_window_functions.sql

# 4. большая таблица для главы 24 (и её же использует глава 25)
psql -d learning_shop -f guide/snippets/24_indexes_explain.sql

# 5. проект: SQL и pandas-часть
psql -d learning_shop -f guide/snippets/26_project.sql
Замечание

SQL-файлы предполагают базу learning_shop. Файлы глав 19–26 можно запускать по одному: каждый начинается с комментария и не меняет данные, кроме 24_indexes_explain.sql и ref_sql_setup.sql, которые создают orders_big. Для справочника достаточно ref_sql_setup.sql: он идемпотентен и не пересоздаёт данные.
