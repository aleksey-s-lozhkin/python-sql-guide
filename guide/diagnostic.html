02Задачи

01 Что выведет код?
задача 01python
a = [1, 2, 3]
b = a
b.append(4)
print(a)
Показать ответ

[1, 2, 3, 4]. Присваивание не копирует список: b и a — два имени одного объекта.

Тема: глава 03, «второе имя или копия».

02 Что произойдёт?
задача 02python
t = (1, 2, 3)
t[0] = 10
Показать ответ

TypeError: 'tuple' object does not support item assignment. Tuple неизменяем: нельзя заменить элемент после создания.

Если элементы нужно менять — это список. Тема: глава 03.

03 Почему падает?
задача 03python
prices = {["apple", "fruit"]: 120}
Показать ответ

TypeError: unhashable type: 'list'. Список изменяем, у него нет стабильного хеша, поэтому он не может быть ключом.

Исправление: {("apple", "fruit"): 120}. Тема: глава 02 и глава 03.

04 Что выведет код?
задача 04python
grid = [[0]] * 2
grid[0].append(1)
print(grid)
Показать ответ

[[0, 1], [0, 1]]. Умножение повторяет ссылку на один и тот же внутренний список.

Правильно: [[0] for _ in range(2)]. Тема: глава 03.

05 Что выведет код?
задача 05python
def f(x, acc=[]):
    acc.append(x)
    return acc

print(f(1), f(2))
Показать ответ

[1] [1, 2]. Значение по умолчанию вычисляется один раз при определении функции и живёт между вызовами.

Исправление: acc=None и создание списка внутри. Тема: глава 03, ошибки.

06 Напишите: сумма заказов по пользователям

Для каждого пользователя посчитайте сумму заказов. Только стандартная библиотека Python.

задача 06python
orders = [
    {"user": "Anna", "amount": 1200},
    {"user": "Ivan", "amount": 800},
    {"user": "Anna", "amount": 500},
]
# ожидается: {'Anna': 1700, 'Ivan': 800}
Показать ответ
решениеpython
totals = {}
for order in orders:
    user = order["user"]
    totals[user] = totals.get(user, 0) + order["amount"]

# или короче:
from collections import defaultdict
totals = defaultdict(int)
for order in orders:
    totals[order["user"]] += order["amount"]

Тема: глава 02 и глава 06.

07 Удалите дубликаты, сохранив порядок
задача 07python
tags = ["sql", "python", "sql", "pandas", "python"]
# ожидается: ['sql', 'python', 'pandas']
Показать ответ

list(dict.fromkeys(tags)). Словарь помнит порядок вставки, а повторный ключ не создаёт новую запись.

Если порядок не важен — list(set(tags)). Тема: глава 02, глава 04.

08 Что вернёт sort() и как получить копию?
задача 08python
nums = [3, 1, 2]
result = nums.sort()
print(result, nums)
Показать ответ

None [1, 2, 3]. sort() сортирует на месте и возвращает None. Отсортированная копия — sorted(nums).

Тема: глава 03.

09 Объясните разницу в скорости

Почему "anna" in users_set работает быстрее, чем "anna" in users_list, и от чего зависит эта разница?

Показать ответ

Множество — хеш-таблица: элемент ищется по вычисленному адресу, в среднем O(1). Список просматривает элементы по порядку — O(n). На 10 элементах разница незаметна, на миллионе — тысячи раз.

Ограничение: множество тратит память и требует hashable-элементов. Тема: глава 02, глава 04.

10 Что выведет код?
задача 10python
box = (1, [2, 3])
box[1].append(4)
print(box)
Показать ответ

(1, [2, 3, 4]). Tuple защищает ссылки, а не содержимое: заменить элемент нельзя, но вложенный список менять можно.

Тема: глава 03, глава 02 — почему такой tuple нельзя сделать ключом.
