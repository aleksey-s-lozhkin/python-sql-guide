У str любая «правка» — upper, replace, конкатенация — создаёт новую строку за O(n). У frozenset операции над наборами стоят столько же, сколько у set, но изменить его нельзя: любое «изменение» — новый объект.

* в среднем: при плохом распределении хешей возможно O(n), но это исключение. Точные замеры зависят от машины — поэтому в главах цена проверяется лабораторией, а не берётся на веру.

04Конвертации между типами

Чаще всего меняют тип, чтобы воспользоваться чужим методом: строка → список для разбора, список → множество для дедупликации, множество → список для вывода, словарь → список пар для сортировки.

конвертацииpython
nums = [3, 1, 2, 3]
print(list(set(nums)))                 # порядок не гарантирован
print(list(dict.fromkeys(nums)))       # порядок сохранён
print(set(nums))

print(list({"a": 1, "b": 2}.items()))  # dict → список пар
print(dict(zip(["a", "b"], [1, 2])))   # две последовательности → dict
print(tuple([1, 2]))                   # list → tuple

print("a,b,c".split(","))              # str → список
print(",".join(["a", "b", "c"]))       # список → str
print(frozenset([3, 1, 3]))            # set → frozenset
[1, 2, 3] [3, 1, 2] {1, 2, 3} [('a', 1), ('b', 2)] {'a': 1, 'b': 2} (1, 2) ['a', 'b', 'c'] a,b,c frozenset({1, 3})
Правило

Чтобы сохранить порядок при удалении дублей — dict.fromkeys. set порядок теряет: для множества строк он может отличаться даже между запусками.
