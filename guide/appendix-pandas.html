Чем pandas отличается от справочника Python-коллекций

У list и dict была честная цена O(1)/O(n). В pandas вместо неё — память и копирование: операция может быть векторизованной, а может копировать таблицу. Поэтому в таблицах ниже «цена» — это примечание о копии/view, а не выдуманная асимптотика.

03«Цена» в pandas: копия, view и CoW

В pandas 3.0 по умолчанию включён Copy-on-Write. Производные объекты — срез df[mask], выбор колонок df[["a"]], результат rename — ведут себя как копии: правка «ветки» не меняет исходную таблицу. Но df2 = df — это не копия, а второе имя того же объекта; независимую копию даёт df.copy().

  • Изменение — через .loc. df.loc[df["amount"] > 1000, "flag"] = True работает; цепочка df[df["amount"] > 1000]["flag"] = True — не меняет исходную таблицу.
  • Память считается. df.memory_usage(deep=True) показывает вклад колонок; строки в pandas 3 хранятся как dtype str, а не object.
  • Векторизация важнее циклов. Если тянет написать for по строкам — сначала ищите колонковую операцию: маску, .str, .dt, groupby.

04Конвертации: dict, список, CSV, индекс

конвертацииpython
import io
import pandas as pd

s = pd.Series({"anna": 1200, "ivan": 800}, name="amount")
df = pd.DataFrame({"user": ["anna", "olga"], "amount": [1200, 500]})

print(df.to_dict("records"))                 # DataFrame → список словарей
print(df["user"].tolist())                   # Series → список
print(df.set_index("user").index.tolist())   # колонка → индекс
print(df.reset_index().columns.tolist())     # индекс → колонка
print(pd.read_csv(io.StringIO("user,amount\nanna,1200\n")).shape)
[{'user': 'anna', 'amount': 1200}, {'user': 'olga', 'amount': 500}] ['anna', 'olga'] ['anna', 'olga'] ['index', 'user', 'amount'] (1, 2)

Вывод получен на pandas 3.0.1. Для чтения CSV из файла — pd.read_csv("path"); из строки (так удобнее в лабораториях) — io.StringIO.
