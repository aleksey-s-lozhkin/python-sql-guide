B3. Соединение без потерь 2 балла

Добавьте к заказам имена пользователей, сохранив все заказы, и найдите заказ без пользователя.

B3python
orders = pd.DataFrame({"order_id": [1, 2], "user_id": [10, 30]})
users = pd.DataFrame({"user_id": [10], "name": ["anna"]})
Показать решение
решениеpython
merged = orders.merge(users, on="user_id", how="left",
                      validate="many_to_one", indicator=True)
print(len(merged) == len(orders))
print(merged[merged["_merge"] == "left_only"])

Критерии. left join + validate + indicator; проверка числа строк.

C2. Даты и форма таблицы 2 балла

Получите выручку по месяцам в pandas и в SQL. Почему в SQL нет pivot?

Показать решение
pandas и SQLpython
orders["date"] = pd.to_datetime(orders["date"])
monthly = orders.groupby(orders["date"].dt.to_period("M"))["amount"].sum()
sqlsql
SELECT DATE_TRUNC('month', created_at) AS month, SUM(amount)
FROM orders GROUP BY 1 ORDER BY 1;

В SQL таблица всегда «длинная»: pivot — это преобразование для отчёта, его делают в приложении или через CASE WHEN.
