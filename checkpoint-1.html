B1. Сводка по заказам 2 балла

По списку заказов получите для каждого пользователя количество и сумму, затем найдите пользователя с максимальной суммой.

B1python
orders = [
    {"user": "Anna", "amount": 1200},
    {"user": "Ivan", "amount": 800},
    {"user": "Anna", "amount": 500},
    {"user": "Petr", "amount": 2100},
]
Показать решение
решениеpython
from collections import defaultdict

stats = defaultdict(lambda: {"count": 0, "total": 0})
for o in orders:
    s = stats[o["user"]]
    s["count"] += 1
    s["total"] += o["amount"]

best = max(stats, key=lambda u: stats[u]["total"])
print(dict(stats))
print(best)
{'Anna': {'count': 2, 'total': 1700}, 'Ivan': {'count': 1, 'total': 800}, 'Petr': {'count': 1, 'total': 2100}} Petr

Критерии. Нет pandas; используется get/defaultdict; max с ключом, а не сортировка. В объяснении — O(n) по заказам и O(k) по пользователям.

B3. Топ-3 слова 2 балла

Найдите три самых частых слова. Объясните, что произойдёт при равных частотах и как получить стабильный порядок.

B3python
text = "sql python sql pandas python sql airflow"
Показать решение
решениеpython
from collections import Counter

counts = Counter(text.split())
print(counts.most_common(3))

# стабильный порядок при равных частотах:
print(sorted(counts.items(), key=lambda kv: (-kv[1], kv[0]))[:3])
[('sql', 3), ('python', 2), ('pandas', 1)] [('sql', 3), ('python', 2), ('airflow', 1)]

Критерии. Использован Counter; объяснено, что most_common при равных частотах сохраняет порядок первого появления, а для детерминированного вывода нужен явный ключ сортировки.

B4. Последние пять событий 2 балла

Храните последние пять событий пользователя в порядке поступления. Объясните, почему для этого не подходит обычный список.

B4python
events = ["login", "view", "search", "click", "pay", "logout", "export"]
Показать решение
решениеpython
from collections import deque

last = deque(maxlen=5)
for event in events:
    last.append(event)

print(list(last))
['search', 'click', 'pay', 'logout', 'export']

Критерии. deque с maxlen; объяснено, что у списка удаление из начала — O(n), а у deque — O(1), и что maxlen сам вытесняет старые элементы.

C1. Та же группировка в pandas и SQL 2 балла

Показать решение

df = pd.DataFrame(orders)

C2. Фильтр по запрещённым и ловушка NULL 2 балла

Есть множество запрещённых ID. Отфильтруйте пользователей в Python. Как записать то же в SQL? И почему NOT IN (SELECT ...) может вернуть пустой результат, если в подзапросе есть NULL?

Показать решение
pythonpython
banned = {1, 2, 3}
users = [{"id": 1}, {"id": 4}, {"id": 5}]

active = [u for u in users if u["id"] not in banned]
print(active)   # [{'id': 4}, {'id': 5}]
[{'id': 4}, {'id': 5}]
sqlsql
SELECT * FROM users
WHERE id NOT IN (SELECT user_id FROM bans);

-- надёжнее: NOT EXISTS не ломается на NULL
SELECT * FROM users u
WHERE NOT EXISTS (SELECT 1 FROM bans b WHERE b.user_id = u.id);

Почему пусто. NOT IN — это цепочка сравнений с NULL, а любое сравнение с NULL даёт UNKNOWN, а не TRUE. Поэтому строка не проходит фильтр. NOT EXISTS проверяет наличие строки и от NULL не зависит.

Критерии. Python-фильтр по set; SQL-вариант; объяснение трёхзначной логики или хотя бы вывод «NOT EXISTS безопаснее».
